Данный репозиторий содержит структурированные материалы для подготовки к техническим собеседованиям на позиции Go Backend и общего Backend-разработчика в ведущие IT-компании, которые изначально систематизировались для личного использования. Ввиду субъективной структуры базы знаний ее практическая польза может варьироваться, поэтому для обеспечения удобной навигации и визуализации связей настоятельно рекомендуется открыть директорию `knowledge` в среде Obsidian. Всем удачи на собеседованиях!


P.S. база скорее всего будет изменяться и пополняться новыми знаниями
